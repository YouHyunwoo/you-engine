# You-Engine 코드 정비 설계

## 목표

기존 코드의 버그 수정, 구조 개선, 문서화를 통한 엔진 품질 향상

## 우선순위

1. **안정성** - 버그 수정, 엣지 케이스 처리
2. **구조 개선** - 아키텍처 리팩토링, 코드 정리
3. **문서화** - 코드 이해도 향상

## 범위

- **포함**: `you/` 폴더 (엔진 코어)
- **제외**: `examples/` 폴더 (별도 git repo로 관리)

## 개발 방식

### 브랜치 전략
- **피처 브랜치** - 작업별로 브랜치 생성 후 머지
- **Squash merge** - 피처당 하나의 커밋으로 압축

### 코드 리뷰
- **혼합 방식** - 중요한 변경은 PR, 작은 변경은 대화에서 리뷰
- **PR 기준**: API 변경, 핵심 로직 변경

### 커밋 메시지
- **Conventional Commits** 형식 사용
- 접두사: `feat:`, `fix:`, `refactor:`, `docs:`, `test:`, `chore:` 등
- 언어: 한국어

### 버전 관리
- **Semantic Versioning** (MAJOR.MINOR.PATCH)
- **현재 상태**: 0.x.x (초기 개발 단계)
- **패키지 매니저**: pnpm

## 작업 흐름

```
문제 발견 → 코드 리뷰 설명 → 수정 + 테스트 → 커밋 → 반복
```

## 테스트

- **프레임워크**: Vitest
- **범위**: 단위 테스트만
- **커버리지 목표**: 80% 이상

## 산출물

- 정비된 엔진 코드
- Vitest 기반 테스트 코드
- `.claude/CLAUDE.md`에 개발 규칙 정리
  - 코드 스타일 (네이밍, 포맷팅, 패턴)
  - 개발 프로세스 (커밋 규칙, 테스트 작성 규칙)
  - 아키텍처 가이드 (모듈 구조, 의존성 규칙, 확장 방법)

## 언어

- 커밋 메시지: 한국어
- 코드 리뷰: 한국어
