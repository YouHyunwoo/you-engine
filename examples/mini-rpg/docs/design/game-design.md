# Mini RPG 게임 설계

## 게임 개요

바람의나라 스타일의 2.5D 탑다운 RPG. 평화로운 분위기에서 귀여운 몬스터들과 전투하며 탐험하는 게임.

## 핵심 컨셉

| 항목 | 내용 |
|------|------|
| **시점** | 탑다운 2.5D |
| **이동** | 4방향 (위/아래/좌/우), 점프 없음 |
| **전투** | 장비에 따라 근접/원거리 |
| **진행** | 전투 + 탐험 + 수집 |
| **분위기** | 평화롭고 아기자기함 |

## 스탯 시스템

3가지 스탯으로 단순화:

| 스탯 | 설명 |
|------|------|
| **HP** | 체력. 0이 되면 사망 |
| **공격력** | 적에게 주는 데미지 |
| **방어력** | 받는 데미지 감소 |

레벨업 시 스탯 포인트 획득, 자유 배분.

## 몬스터

### 초반 몬스터
- **버섯 (Mushroom)** - 느린 이동, 근접 공격, 낮은 HP
- **개미 (Ant)** - 빠른 이동, 약한 공격, 무리 등장

### 중반 이후 (확장 예정)
- 슬라임, 꿀벌 등 추가 가능

## 맵 구성

여러 구역으로 분리:

```
[마을] ─── [숲] ─── [동굴]
              │
           [호수]
```

| 구역 | 특징 |
|------|------|
| **마을** | 안전지대, NPC, 상점 |
| **숲** | 버섯, 개미 출현 |
| **동굴** | 강한 몬스터 (후반) |
| **호수** | 힐링 포인트, 낚시? |

## 수집 시스템

### 1. 아이템 드롭
- 몬스터 처치 시 확률적 드롭
- 장비 (무기, 방어구)
- 소비 아이템 (포션)
- 재료 아이템

### 2. 퀘스트
- NPC 대화로 수주
- 목표: 몬스터 처치, 아이템 수집, 탐험
- 보상: 경험치, 골드, 아이템

### 3. 도감
- 발견한 몬스터 기록
- 획득한 아이템 기록
- 완성도에 따른 보상?

## 전투 시스템

### 공격 방식
- **근접 무기** (검, 도끼): 짧은 사거리, 높은 데미지
- **원거리 무기** (활, 지팡이): 긴 사거리, 투사체 발사

### 데미지 계산
```
최종 데미지 = 공격력 - 방어력
최소 데미지 = 1
```

## 아트 스타일

### 프로토타입 (1차)
- 모든 캐릭터/몬스터: 간단한 도형 (원, 사각형)
- 색상으로 구분
  - 플레이어: 파란색
  - 버섯: 빨간색 + 흰색 점
  - 개미: 검정색
  - NPC: 녹색

### 최종 (2차 - 선택)
- 픽셀아트 또는 외부 에셋

## 구현 우선순위

### Phase 1: 코어 시스템
1. 플레이어 이동 (4방향)
2. 기본 충돌 처리
3. 간단한 맵 렌더링

### Phase 2: 전투
4. 몬스터 AI (추적, 공격)
5. 플레이어 공격
6. HP/데미지 시스템

### Phase 3: 진행 시스템
7. 레벨업/경험치
8. 아이템 드롭
9. 인벤토리

### Phase 4: 콘텐츠
10. 여러 맵 구역
11. NPC/퀘스트
12. 도감
